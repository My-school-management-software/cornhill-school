Recovery readiness checklist

  1. Confirm the latest encrypted export exists outside the main office computer.
  2. Verify the encrypted file can be opened by the authorised administrator.
  3. Confirm the separate treatment of uploaded files, authentication accounts and platform configuration.
  4. Perform a restore rehearsal in a separate project before relying on recovery.
  5. Record the date, operator and result of the rehearsal in the school's backup log.

This page does not claim to inspect Vercel build logs, run a complete backup, or prove a database restore.

Safe connection steps

  1. Record the terminal manufacturer and exact model number.
  2. Confirm it supports a documented export or local/network API.
  3. Map each enrolled staff reference to the correct school staff account.
  4. Test clock-in and clock-out using designated test staff accounts.
  5. Compare device logs with the existing attendance register before enabling routine imports.

Do not purchase a device based only on a generic USB fingerprint description. Device compatibility must be verified.
